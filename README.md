# binwatch-8051
# Бинарные наручные часы (AT89C51 + DS1307)

Курсовой проект по дисциплине **«Микроконтроллерные системы»**.  
Устройство реализует бинарные наручные часы на микроконтроллере семейства **8051** с использованием **RTC DS1307**.  
Время (часы, минуты, секунды) отображается набором светодиодов в двоичном формате. Настройка выполняется тремя кнопками **OK / INC / DEC**.  
Обмен с DS1307 организован по **I²C**, реализованному программно (**bit-bang**). Проект смоделирован и отлажен в **Proteus**.

---

## Возможности

- Отображение текущего времени:
  - часы, минуты, секунды — **бинарная LED-индикация**
- Ручная установка и корректировка времени:
  - **OK** — вход/переключение параметров/выход
  - **INC** — увеличение значения
  - **DEC** — уменьшение значения
- Переключение формата **12/24 ч** (длинное нажатие OK)
- Сохранение хода времени при отключении основного питания
  - за счёт резервного питания **VBAT** у DS1307

---

## Аппаратная часть

**Микроконтроллер:** AT89C52 (семейство 8051)  
**RTC:** DS1307 + кварц 32,768 кГц + резервная батарея  
**Питание:** +5 В (основное), VBAT (резерв RTC)

### Индикация

- Часы: **4 LED** (веса 1, 2, 4, 8)
- Минуты: **6 LED** (веса 1, 2, 4, 8, 16, 32)
- Секунды: **6 LED** (веса 1, 2, 4, 8, 16, 32)
- AM/PM: **2 LED** (для 12-часового режима)

### Органы управления

- **OK**
- **INC**
- **DEC**

### Подключение (основное)

- LED часов + AM/PM: порт **P0**
- LED минут: **P1.0–P1.5**
- LED секунд: **P2.0–P2.5**
- Кнопки:
  - INC — **P3.0**
  - DEC — **P3.1**
  - OK — **P3.2**
- I²C (bit-bang):
  - SCL — **P1.6**
  - SDA — **P1.7**
- Подтяжки I²C: ~**4.7 кОм** к +5 В  
- Для P0 используется подтяжка (например, RESPACK)

## Программная часть

Архитектура ПО разделена на подсистемы:

- **Хранение состояния:** `hh`, `mm`, `ss`, флаги режима и UI
- **Индикация:** функции обновления битов портов по двоичному значению времени
- **I²C (bit-bang):**
  - старт/стоп, запись/чтение байтов, обработка ACK/NACK
- **Работа с DS1307:**
  - чтение/запись регистров, преобразования **BCD ↔ BIN**
- **Таймер T0:**
  - формирование **1 мс** тика и флага **1 с**
- **Обработка кнопок:**
  - различение короткого/длинного нажатия OK без аппаратного дебаунса
- **Основной цикл:**
  - чтение времени из RTC каждую секунду и обновление индикации  
  - fallback-счёт времени при отсутствии RTC
